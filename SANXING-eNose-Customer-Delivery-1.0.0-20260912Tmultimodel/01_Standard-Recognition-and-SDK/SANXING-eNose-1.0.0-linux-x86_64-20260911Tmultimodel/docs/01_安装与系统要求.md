# 安装与系统要求

## 已验证环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Ubuntu 20.04.6 LTS |
| CPU 架构 | Linux x86_64 |
| 图形界面 | 运行 `enose-demo` 时需要桌面显示环境 |
| 电子鼻串口 | `/dev/ttyCH341USB*` 或 `/dev/ttyUSB*` |
| 串口参数 | 115200 baud、8 数据位、无校验、1 停止位 |
| 推理服务端口 | TCP 5006，默认仅监听 `127.0.0.1` |
| Python SDK | Python 3.8 或更高版本 |

其他 Linux 发行版或 CPU 架构应先完成兼容性验收。三个 `application/` 目录均为
整体运行目录，不要单独移动其中的可执行文件或 `_internal/`。

## 文件校验与解压

```bash
sha256sum -c SHA256SUMS.txt
tar -xzf packages/<组件包名称>.tar.gz
cd <解压后的组件目录>
sha256sum -c SHA256SUMS
```

外层和组件内校验均成功，表示传输和解压过程中文件保持完整。

## 串口识别

连接电子鼻后执行：

```bash
ls -l /dev/ttyCH341USB* /dev/ttyUSB* 2>/dev/null
python3 -m serial.tools.list_ports -v
dmesg | tail -n 30
```

厂商 CH341 Linux 驱动可能创建 `/dev/ttyCH341USB0`，即使 pyserial 没有枚举，
参考客户端仍会补充扫描 `/dev/ttyCH341USB*`。

## 串口权限

Ubuntu 通常使用 `dialout` 组管理串口：

```bash
sudo usermod -aG dialout "$USER"
```

执行后注销并重新登录，再通过 `groups` 确认当前用户属于 `dialout`。可以使用
`ls -l /dev/ttyCH341USB0` 查看设备所属组。

## Python SDK 依赖

基础 SDK 依赖：

```text
pyserial==3.5
```

使用 XLSX 保存时还需要：

```text
openpyxl==3.1.5
```

在线环境可直接安装 wheel，由 pip 解析依赖：

```bash
python3 -m pip install \
  sanxing-enose-device-sdk-1.0.0-linux-x86_64/python/enose_sdk-1.0.0-py3-none-any.whl
```

完全离线的 Python 环境需要由部署方提前准备上述依赖 wheel。免安装参考客户端
`application/enose-client` 已包含运行依赖，不需要 Python 环境。

## 数据目录

建议为每次测试指定独立目录：

```bash
mkdir -p "$HOME/enose-client-data"
```

参考客户端默认以 CSV 保存，每 50000 行分卷。可以通过 `--save-dir`、
`--save-format` 和 `--rotate-rows` 调整。
