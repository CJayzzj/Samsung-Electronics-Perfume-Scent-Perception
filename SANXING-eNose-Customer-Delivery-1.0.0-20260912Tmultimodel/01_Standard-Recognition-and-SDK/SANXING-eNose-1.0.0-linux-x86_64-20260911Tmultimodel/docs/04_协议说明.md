# 电子鼻推理服务接口协议 v1

推理服务负责接收传感器帧，并返回处理状态、事件状态和最终识别结果。客户只需
按照本协议提供输入数据，不需要执行额外的数据预处理。

传输使用 TCP + UTF-8 JSONL，一行一个 JSON 对象。连接建立后推理服务先发送一次
`ready`，随后每个合法 `frame` 严格返回一个 `frame_response`。

当前版本一个服务进程同时处理一个客户端连接。单行 JSON 消息不得超过 64 KiB。

## ready

```json
{"type":"ready","protocol_version":1,"device_id":"SX_01","sample_rate_hz":1.0,"model_id":"samsung-cascade-20260911T062309Z-front-rbf-c10-rear-rbf-c1-enose-core-v1","algorithm_version":"enose-core-v1","classes":{"P01":"GETARIA","P02":"LEDIX","P03":"NO-CO","P04":"MUSCARA","O01":"异味","AIR":"空气"},"input":{"sensor_count":16,"input_domain":"adc_counts","adc_full_scale":4096.0,"matched_resistance_kohm":10.0}}
```

客户只发送原始 ADC 数据。`input` 说明当前服务要求的传感器数量、输入域和有效
量程；客户端应根据这些值构造输入帧。`model_id` 和 `algorithm_version` 是用于
运行记录与兼容性核对的不透明标识，客户端不得解析或依赖其命名格式。

## 输入帧

输入字段固定为六项；不接受额外字段、数字字符串、浮点ADC、零值或负值。

```json
{"type":"frame","sequence":12345,"timestamp_ms":1786000000000,"adc":[2011,1985,2067,2044,1976,2018,2131,2005,1892,1914,2067,2108,1953,2026,2091,1987],"temperature_c":25.36,"humidity_rh":61.42}
```

`adc` 必须正好包含16个整数，并满足
`1 <= adc[i] < ready.input.adc_full_scale`。推理服务完成字段校验和内部处理后返回
与该 `sequence` 对应的 `frame_response`。

## 无最终结果

```json
{"type":"frame_response","sequence":12345,"gate_score":0.324284,"event_peak_score":null,"result":null}
```

`gate_score` 是当前输入帧的服务状态评分，每个合法输入帧都返回。
`event_peak_score` 是事件确认帧的服务状态评分，其他帧为 `null`。这两个字段用于
运行监控，不是概率、置信度或 ppm，取值不限制在 0～1；客户端不得根据其数值
自行推导识别结果，应以 `result` 为准。

## 有最终结果

```json
{"type":"frame_response","sequence":12348,"gate_score":0.324284,"event_peak_score":1.226145,"result":{"event_id":"E000031","class_code":"P02","label":"LEDIX","response_time_s":9.0}}
```

`result` 只有在服务产生最终识别结果时才非空。必需字段为 `event_id`、
`class_code`、`label`；`response_time_s` 可选。一次物理响应周期最多产生一个非空
`result`；结果产生后，本周期的后续帧继续返回 `gate_score`，但 `result` 和
`event_peak_score` 均为 `null`。服务进入下一响应周期后才可能产生新的非空结果。

`gate_score` 与 `event_peak_score` 反映的状态不同，两者数值不要求相等。客户端
应将这两个字段作为不透明监控值，并仅依据 `result` 是否为空处理识别业务。

## 错误

```json
{"type":"error","code":"INVALID_FRAME","message":"request failed","sequence":12345}
```

服务返回稳定错误码和简短说明；详细异常记录在服务本地日志中，响应中不包含
模型路径、Python 异常栈或内部处理状态。只有请求中的 `sequence` 已通过整数及范围
校验时，错误响应才会携带 `sequence`；非法字符串、负数或越界序号不会被原样
回传。

常见错误码：

| 错误码 | 含义 |
|---|---|
| `MESSAGE_TOO_LARGE` | 单行消息超过 64 KiB |
| `INVALID_UTF8` | 消息不是合法 UTF-8 |
| `INVALID_JSON` | JSON 语法错误 |
| `INVALID_MESSAGE` | 消息外层结构错误 |
| `INVALID_FIELD` | 字段缺失、类型错误或超出范围 |
| `UNSUPPORTED_TYPE` | 不支持的消息类型 |
| `UNEXPECTED_FIELD` | 消息包含协议未定义字段 |
| `INVALID_FRAME` | 传感器帧长度或数值范围错误 |
| `OUT_OF_ORDER_FRAME` | 帧序号重复、倒退，或时间戳倒退 |
| `INTERNAL_ERROR` | 推理处理发生未预期错误 |

进程启动阶段模型校验失败时，程序向标准输出写出 `STARTUP_FAILED` 错误，并以
非零退出码结束；此时 TCP 服务尚未启动。
