# 故障排查

## 快速诊断命令

```bash
ls -l /dev/ttyCH341USB* /dev/ttyUSB* 2>/dev/null
groups
ss -ltnp | grep ':5006'
./enose-inference-service --self-test
./enose-client --help
```

## 常见问题

| 现象 | 常见原因 | 处理方法 |
|---|---|---|
| 找不到串口 | USB 未连接、驱动未创建设备节点 | 重新插拔设备，查看 `dmesg` 和 `/dev/ttyCH341USB*` |
| `Permission denied` | 当前用户没有串口权限 | 加入 `dialout` 组，注销后重新登录 |
| `Device or resource busy` | 串口被其他程序占用 | 关闭 `enose-demo`、其他 `enose-client` 或串口工具 |
| `Connection refused` | 推理服务未启动或地址端口错误 | 先启动服务，核对 `--inference-host/--inference-port` |
| `Address already in use` | TCP 5006 已被占用 | 使用 `ss -ltnp` 查找进程，或为服务和客户端同时更换端口 |
| `STARTUP_FAILED` | 模型目录不完整或文件校验失败 | 核对四个模型文件，使用 `--bundle ... --self-test` |
| `INVALID_FRAME` | ADC 数量、范围、温湿度或字段类型错误 | 按 `04_协议说明.md` 检查输入帧 |
| `OUT_OF_ORDER_FRAME` | 序号重复/倒退或时间戳倒退 | 每条连接从连续序号开始，并使用单调不倒退的时间戳 |
| 长时间没有最终结果 | 设备仍在预热、样品状态不稳定或当前响应尚未完成 | 等待预热，保持测试位置，确认服务持续返回 `frame_response` |
| XLSX 保存失败 | 未安装 `openpyxl` 或目录不可写 | 安装 XLSX 可选依赖并检查 `--save-dir` 权限 |
| GUI 无法启动 | 没有桌面显示环境或 Qt 依赖加载失败 | 在 Ubuntu 桌面会话中启动，并保持 `_internal/` 完整 |
| 数据文件没有识别标签 | 对应帧未产生最终结果或退出前响应未返回 | 查看终端 WARN/ERROR，确认推理连接持续正常 |

## 查看推理服务日志

前台运行时日志输出在当前终端。systemd 部署时执行：

```bash
journalctl -u enose-inference-service.service -n 100 --no-pager
```

持续跟踪：

```bash
journalctl -u enose-inference-service.service -f
```

## 收集问题信息

提交问题时建议提供：

- `BUILD_INFO.txt` 和使用的模型 `manifest.json`；
- 操作系统版本：`cat /etc/os-release`；
- CPU 架构：`uname -m`；
- 串口节点与权限：`ls -l /dev/ttyCH341USB*`；
- 完整启动命令；
- 终端错误信息或 systemd 日志；
- 问题发生时间和可复现步骤。

模型文件和原始采集数据应通过双方约定的安全渠道传输。
