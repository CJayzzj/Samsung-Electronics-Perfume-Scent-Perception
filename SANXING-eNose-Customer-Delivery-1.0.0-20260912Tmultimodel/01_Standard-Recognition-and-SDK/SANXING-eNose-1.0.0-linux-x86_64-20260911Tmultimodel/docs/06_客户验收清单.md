# 客户验收清单

建议按顺序执行，并记录执行人、日期和结果。

## 1. 交付完整性

- [ ] `sha256sum -c SHA256SUMS.txt` 全部成功。
- [ ] 三个组件压缩包均可解压。
- [ ] 每个组件目录执行 `sha256sum -c SHA256SUMS` 全部成功。

## 2. 运行环境

- [ ] 操作系统和 CPU 架构符合 `01_安装与系统要求.md`。
- [ ] 电子鼻连接后出现 `/dev/ttyCH341USB*` 或约定串口。
- [ ] 当前用户具有串口读写权限。
- [ ] TCP 5006 未被其他程序占用。

## 3. 推理服务

- [ ] 默认模型执行 `./enose-inference-service --self-test` 成功。
- [ ] 输出 `type=ready`、正确的 `device_id` 和 `model_id`。
- [ ] 使用指定 `--bundle` 时自检成功。
- [ ] 服务启动后 TCP 5006 处于监听状态。
- [ ] `Ctrl+C` 或 `systemctl stop` 可以正常停止服务。

## 4. 设备接入参考客户端

- [ ] `./enose-client --help` 正常显示参数。
- [ ] 可以连接推理服务并显示 `INFERENCE_READY`。
- [ ] 可以打开电子鼻串口并显示 `SENSOR_STARTED`。
- [ ] 持续接收 16 路 ADC、温度和湿度。
- [ ] 按 `Ctrl+C` 后安全退出并显示保存帧数。
- [ ] `--save-dir` 中生成 CSV 或 XLSX。
- [ ] 数据文件包含 `Recognition_Result` 列。

## 5. 识别演示客户端

- [ ] `./enose-demo` 正常打开。
- [ ] 可以选择并加载模型。
- [ ] 可以选择电子鼻串口并连接。
- [ ] 预热倒计时正常，预热结束前不能开始推理。
- [ ] 曲线持续更新并显示温度、湿度。
- [ ] 完成一次样品响应后显示识别结果。
- [ ] 识别结果出现后提示可以取走样品。

## 6. Python SDK

- [ ] wheel 可以安装到 Python 3.8 或更高版本环境。
- [ ] `python3 -c "from enose_sdk import InferenceClient"` 成功。
- [ ] `docs/examples/sdk_client_example.py` 可以连接推理服务并收到响应。
- [ ] `docs/examples/serial_inference_example.py --help` 正常显示参数。
- [ ] SDK 入参、出参和错误响应符合 `03_SDK_API手册.md` 与 `04_协议说明.md`。
